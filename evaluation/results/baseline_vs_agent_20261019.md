# 固定 RAG 基线与当前 Agent 的量化对照

整理日期：2026-10-19；数据来自 2026-10-17 的 CodeZ 实测。本次仅重新核算和整理既有结果，没有重新调用模型，也没有调整生产行为。

当前证据支持“部分最终引用覆盖改善，代价是耗时和调用增加”；同题配对的回答相关性、事实一致性下降，尚未验证整体回答质量提升。这里将 Agent 视为优化候选，不能预设它已经完成有效优化。

## 当前可以复述的结论

> 在同一CodeZ模型、同一法规索引和同一30题开发集下，当前Agent相对固定RAG的最终引用Recall@5从83.33%提高到88.10%（+4.76个百分点，较未舍入基线相对+5.71%）；7道多法源题的全部gold命中率从57.14%提高到71.43%（+14.29个百分点）。边界正确拒答维持9/9，但正式answered题数维持18/21；配对RAGAS相关性和事实F1下降，平均请求耗时约为4.23倍，模型调用为5倍。当前支持局部证据覆盖收益，尚不能声称整体回答质量或性价比改善。

若继续优化，验收应在相同冻结基线与协议下同时检查检索覆盖、正式作答/澄清、配对RAGAS、回退率、时延与用量。需要在独立保留题集上再次比较；不能仅靠当前开发集上的局部增量声称泛化提升，也不能把历史离线规则成绩换成当前模型Agent的成绩。
